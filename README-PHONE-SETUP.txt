OPTION B: BUILD A REAL ANDROID APK USING YOUR PHONE + GITHUB
1. Create a FREE account at https://github.com on your Android phone.
2. Create a NEW PUBLIC repository called life-uk-practice. Do not include personal data.
3. Extract this ZIP with Samsung My Files. Upload the Android project files and folders to the repo, preserving paths, including the hidden .github/workflows/build-apk.yml file. GitHub mobile browser may require 'Desktop site' for uploading folders. A laptop is easier but not required.
4. On GitHub open Actions -> Build Android APK -> Run workflow (or push to main).
5. Wait for the build to finish. Under the workflow run, download the LifeUKPractice-debug-APK artifact ZIP.
6. Extract the APK from the artifact ZIP. Open app-debug.apk on Android. Your phone may ask you to allow installing from your file manager. Only install builds you created and trust.
7. The debug APK is FOR TESTING ONLY. To publish on Google Play you need a signed release AAB, a developer account, privacy/disclosure review and any required testing.
8. If the workflow fails, open the failed step and share the error log for troubleshooting. No successful APK build is claimed yet.

GitHub Actions free public repository use is subject to GitHub's current terms and usage limits. This project has no backend, login or network permissions.
